Integrations

GitHub

Connect GitHub so Worklynq can work with your code. It’s the foundation for AI coding agents: Claude uses Worklynq’s GitHub connection to work in your repositories, and Worklynq uses it to open pull requests.

What it does

  • Gives Worklynq access to the repositories you choose — and only those.
  • Lets Claude read, change, and push code in those repositories when you hand it a ticket.
  • Lets Worklynq open the pull request when an agent finishes, so the change is ready for your team to review.

Before you start

  • You need to be your workspace’s System Admin.
  • You need permission in GitHub to install apps on the account or organization that owns your repositories.
  • Decide which repositories Worklynq should work with. You can change this later in GitHub.

Connect GitHub

  1. In Worklynq, open Admin console → Work Configuration → Integrations and, under Developer tools, choose GitHub.
  2. Follow the steps to connect your GitHub account or organization. Installing Worklynq’s GitHub App is the recommended way.
  3. Choose the repositories Worklynq may access.
  4. Approve these permissions on those repositories: Contents: read and write and Pull requests: read and write.
  5. Back in Worklynq, GitHub shows as Connected.

Grant only the repositories Worklynq needs. You can add or remove repositories anytime in your GitHub settings for the app.

Next steps

  • Connect Claude to hand tickets to Claude.
  • Connect Cursor to hand tickets to Cursor’s cloud agents.

Troubleshooting

An agent can’t open the pull request
Check that the app has Contents and Pull requests write permission on that repository, and that branch protection on the base branch allows pull requests from it.
A repository is missing in Worklynq
Add it to the app’s repository access in your GitHub settings, then refresh the Integrations page.
